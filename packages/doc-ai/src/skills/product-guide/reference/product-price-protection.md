# 商品价保

**Impact: MEDIUM** - 商品价保（价格保护）是指商品在买家购买后的一定时限内发生降价，买家可申请退还差价的售后服务机制。合理的价保设置有助于提升买家信任，但也需防范恶意套利与规则滥用。

## 任务清单

- [ ] 确认平台价保政策（保护时长、适用商品范围、触发条件）
- [ ] 核查商品当前价格与历史价格，判断是否满足价保条件
- [ ] 受理买家价保申请并核实差价金额
- [ ] 按平台规则完成退差价操作或拒绝申请并说明原因
- [ ] 记录价保处理结果，避免重复申请

**何时需要「商品价保」说明：**

- 买家反映购买后商品降价，要求退差价
- 商家不确定哪些降价行为会触发价保义务
- 需要了解平台价保时效与差价计算方式
- 处理价保申请被拒后的买家投诉
- 区分「价保退差价」与「退货退款」的适用场景

**与其它操作的边界：**

- **价格调整**：主动修改商品价格的操作，可能触发价保义务
- **促销活动**：部分平台规定活动价不纳入价保范围，需区分判断
- **退货退款**：买家整单退货，与价保退差价是两个独立流程

## 基本流程

1. **买家发起申请** → 在订单详情或售后入口提交价保申请，填写申请时效内的低价凭证。
2. **商家/平台核验** → 确认申请时间是否在价保时效内，核查降价是否为正常销售价（排除闪购、拍卖等特殊场景）。
3. **计算差价** → 差价 = 买家实付单价 − 当前最低价（或申请时价格），按实际购买数量计算。
4. **退差价操作** → 通过原路退款或优惠券形式将差价返还买家（依平台规则）。
5. **记录归档** → 更新订单价保状态，留存处理记录备查。

## 常见场景

### 平台活动降价触发价保

大促（双十一、618 等）前后价格波动大，买家集中申请价保。需提前确认平台规则：活动价是否在价保范围内、价保时长是否有特殊设置，避免批量纠纷。

### 商家主动调价触发价保

商家修改商品售价后，保护期内的历史买家可申请差价退还。建议在调价前评估影响范围，必要时先关闭价保或与买家提前沟通。

### 买家在价保期外申请

超出价保时效的申请，商家可依据平台规则拒绝，但应礼貌说明原因，并引导买家通过其他途径（如优惠券、换购）提升体验。

### 差价极小或含运费争议

部分买家对差价计算方式存疑（是否含运费、是否按件计算）。处理时须以平台规则为准，避免口头承诺超出规则范围。

## 注意事项

- **价保时效**：各平台保护时长不同（常见为 7 天、15 天、30 天），需以平台公示规则为准，不可口头延长。
- **排除场景**：秒杀、拼团、定制商品等特殊商品通常不适用常规价保规则，需在商品详情页明确标注。
- **差价计算基准**：部分平台以「最终实付价」（含优惠券、积分抵扣后）为基准，需仔细核算避免多退少退。
- **防范恶意套利**：同一买家频繁申请价保或存在刷单嫌疑时，应按平台申诉流程处理，留存证据。
- **退差价方式**：退款路径（原路退回 vs 优惠券）由平台规则决定，商家不可自行更改。

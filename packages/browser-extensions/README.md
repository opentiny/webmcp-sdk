# OpenTiny NEXT 浏览器扩展使用指南

## 概述

OpenTiny NEXT 浏览器扩展是一个智能助手工具，基于 MCP (Model Context Protocol) 协议，为网页提供 AI 智能交互功能。该扩展支持用户脚本运行，可以在指定网站上提供智能助手服务。

## 功能特性

- 🤖 **智能助手**：基于 MCP 协议的 AI 智能交互
- 🛠️ **用户脚本支持**：在网页中注入 WebMCP 客户端
- 🎨 **页面交互**：支持调用接口（可以获取到已登录用户信息），支持页面元素操作和样式修改，比如修改页面背景颜色
- 🔧 **开发者友好**：支持本地开发和调试
- 🌐 **多站点支持**：可配置不同网站的 WebMCP 客户端

## 安装指南

### 开发者模式安装（推荐）

#### 1. 启用开发者模式

1. 打开浏览器，访问 `chrome://extensions/` 或 `edge://extensions/`
2. 在右上角找到"开发者模式"开关，将其打开
3. 开发者模式启用后，会显示"加载已解压的扩展程序"按钮

#### 2. 加载扩展程序

1. 点击"加载已解压的扩展程序"按钮
2. 选择 `packages/browser-extensions` 文件夹
3. 点击"选择文件夹"完成加载

#### 3. 验证安装

安装成功后，你应该能看到：

- 浏览器工具栏出现 OpenTiny NEXT 扩展图标
- 浏览器页面右下角出现 OpenTiny NEXT logo 图标
- 控制台无错误信息

## 权限配置

### 启用用户脚本权限

由于扩展使用了用户脚本功能，需要特殊权限配置：

1. **访问扩展管理页面**
   - 打开 `chrome://extensions/`
   - 找到 "OpenTiny NEXT" 扩展

2. **允许运行用户脚本**
   - 在扩展详情页面，确保"允许运行用户脚本"选项已启用
   - 如果看到权限警告，点击"允许"确认

## 使用说明

### 基本使用

1. **访问支持网站**
   - 目前支持：`https://opentiny.design`
   - 访问该网站时，扩展会自动激活

2. **查看扩展状态**
   - 点击浏览器工具栏中的扩展图标
   - 查看弹窗中的状态信息

3. **使用侧边栏**
   - 点击扩展图标打开侧边栏
   - 在侧边栏中进行智能交互

### 开发者调试

#### 查看控制台日志

1. **扩展控制台**
   - 访问 `chrome://extensions/`
   - 点击扩展的"检查视图"链接
   - 查看 Service Worker 和 Content Script 日志

2. **网页控制台**
   - 在目标网页按 F12 打开开发者工具
   - 查看 Console 标签页的日志信息

#### 调试用户脚本

1. **查看用户脚本**
   - 访问 `chrome://extensions/`
   - 点击"用户脚本"部分
   - 查看已注册的用户脚本

2. **修改脚本**
   - 编辑 `src/mcp-servers/opentiny.design/index.js`
   - 重新加载扩展程序
   - 刷新目标网页

## 故障排除

### 常见问题

#### 1. 扩展无法加载

**问题**：点击"加载已解压的扩展程序"后无反应

**解决方案**：

- 确保选择了正确的文件夹（包含 `manifest.json`）
- 检查 `manifest.json` 文件格式是否正确
- 查看浏览器控制台是否有错误信息

#### 2. 用户脚本无法运行

**问题**：在网页中看不到智能助手功能

**解决方案**：

- 确认已启用"允许运行用户脚本"权限
- 检查目标网站是否在 `matches` 配置中
- 查看扩展控制台是否有错误日志

#### 3. 权限被拒绝

**问题**：扩展请求权限时被拒绝

**解决方案**：

- 重新安装扩展程序
- 手动授予必要权限
- 检查浏览器安全设置

#### 4. 脚本注入失败

**问题**：控制台显示脚本注入错误

**解决方案**：

- 检查 `src/vendor/next-sdk.js` 文件是否存在
- 确认 `web_accessible_resources` 配置正确
- 清除浏览器缓存后重试

## 开发指南

### 项目结构

```text
packages/browser-extensions/
├── manifest.json              # 扩展配置文件
├── logo.png                   # 扩展图标
├── src/
│   ├── main.js                # 内容脚本
│   ├── service_worker.js      # 后台服务
│   ├── popup.html             # 弹窗页面
│   ├── sidepanel.html         # 侧边栏页面
│   ├── options.html           # 选项页面
│   ├── vendor/
│   │   └── next-sdk.js        # SDK 文件
│   └── mcp-servers/
│       └── opentiny.design/
│           └── index.js       # 用户脚本
```

### 添加新功能

1. **添加新的 MCP 工具**
   - 编辑 `src/mcp-servers/opentiny.design/index.js`
   - 使用 `server.registerTool()` 注册新工具

2. **支持新网站**
   - 修改 `src/main.js` 中的 `urlToolsMap`
   - 添加对应的 MCP 服务器文件

3. **修改扩展权限**
   - 编辑 `manifest.json`
   - 重新加载扩展程序

**注意**：本扩展需要现代浏览器支持，建议使用 Chrome 120+ 版本。

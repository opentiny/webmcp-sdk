# 动态 MCP 工具管理系统 - 实现说明

## 📋 项目概述

本次实现为 Options 页面添加了一个全新的**动态 MCP 工具管理系统**，功能类似油猴脚本管理器，允许用户通过可视化界面创建和管理自定义的 MCP 工具，无需修改代码即可扩展系统功能。

## ✨ 核心特性

### 1. 双标签页设计

使用 OpenTiny Vue 的 Tabs 组件，将页面分为两个功能区：

- **提示词专家配置**：保留原有功能
- **动态工具管理**：新增的工具管理功能

### 2. 工具配置管理

- ✅ 可视化的工具列表，按域名分组展示
- ✅ 内置代码编辑器，支持实时编辑工具代码
- ✅ 域名和 URL 路径匹配规则
- ✅ 工具启用/禁用开关
- ✅ 创建、编辑、删除操作

### 3. 智能匹配机制

- ✅ 按域名自动加载对应工具
- ✅ 支持 URL 路径模式匹配（通配符 `*`）
- ✅ 静态工具和动态工具并存
- ✅ 自动过滤未启用的工具

### 4. 热重载支持

- ✅ 保存配置后自动通知所有页面
- ✅ Background 脚本转发重载消息
- ✅ Content Script 接收并刷新页面

```typescript
interface DynamicMcpTool {
  id: string              // 唯一ID（如 tool_1736842320000）

}
```

#### URL 匹配逻辑

```typescript
function matchesUrlPattern(url: string, domain: string, pattern?: string): boolean {
  // 1. 检查域名是否匹配
  if (!urlObj.hostname.includes(domain)) return false
  
  // 2. 如果没有 pattern，匹配所有路径
  if (!pattern) return true
  
  // 3. 将通配符转换为正则表达式
  const regexPattern = pattern
    .replace(/[.+?^${}()|[\]\\]/g, '\\$&')  // 转义特殊字符
    .replace(/\*/g, '.*')                     // * 转为 .*
  
  // 4. 正则匹配路径
  return new RegExp(`^${regexPattern}$`).test(urlObj.pathname)
}
```

#### 代码执行机制

```typescript
export function registerDynamicTool(tool: DynamicMcpTool, server: any, cookie: any): boolean {
  try {
    // 使用 Function 构造函数执行用户代码
    const codeWrapper = `
      return (function() {
        ${tool.code}
      })();
    `
    
    const moduleFactory = new Function(codeWrapper)
    const moduleExports = moduleFactory()
    
    // 获取默认导出
    const toolFunction = moduleExports.default || moduleExports
    
    // 执行工具注册
    toolFunction({ server, z, cookie })
    
    return true
  } catch (e) {
    console.error(`工具注册失败: ${tool.name}`, e)
    return false
  }
}
```

### 5. 热重载机制

#### 保存时触发 (McpToolManager.vue)

```typescript
async function saveTools() {
  await storage.setMeta(STORAGE_KEYS.DYNAMIC_MCP_TOOLS, { list: tools.value })
  
  // 通知 background 重新加载
  browser.runtime.sendMessage({ type: 'reload-dynamic-mcp-tools' })
}
```

#### Background 转发 (background.ts)

```typescript
browser.runtime.onMessage.addListener((message) => {
  if (message.type === 'reload-dynamic-mcp-tools') {
    // 通知所有 tab
    browser.tabs.query({}).then((tabs) => {
      tabs.forEach((tab) => {
        if (tab.id) {
          browser.tabs.sendMessage(tab.id, { 
            type: 'reload-dynamic-mcp-tools' 
          })
        }
      })
    })
  }
})
```

## 🎯 使用流程

### 用户角度

1. **打开 Options 页面** → 点击扩展图标，选择"选项"
2. **切换到"动态工具"标签** → 查看现有工具或创建新工具
3. **点击"添加工具"按钮** → 打开创建表单
4. **填写工具信息**：
   - 工具名称：如 `my_custom_tool`
   - 匹配域名：如 `github.com`
   - URL 模式：如 `/*/*`（可选）
   - 工具描述：简短说明
   - 工具代码：粘贴或编写代码
5. **保存工具** → 自动存储到 storage
6. **访问目标网站** → 工具自动加载并可用

## 📝 工具代码格式

### 标准格式

```javascript
export default ({ server, z, cookie }) => {
  server.registerTool(
    'tool_name',                    // 工具名称
    {
      title: '工具标题',
      description: '工具描述',
      inputSchema: {                 // 参数定义（使用 Zod）
        param1: z.string().describe('参数1'),
        param2: z.number().optional().describe('参数2（可选）')
      }
    },
    async ({ param1, param2 }) => { // 工具执行函数
      // 工具逻辑
      const result = doSomething(param1, param2)
      
      // 返回结果
      return {
        content: [
          { type: 'text', text: JSON.stringify(result) }
        ]
      }
    }
  )
}
```

### 注册多个工具

```javascript
export default ({ server, z, cookie }) => {
```

## 🔍 集成方式

### 在 Content Script 中集成

```typescript
// entrypoints/content.ts
import { registerAllMcpToolsForUrl } from '@/utils/mcpToolRegistry'

export default defineContentScript({
  matches: ['<all_urls>'],
  async main() {
    const server = createMcpServer()
    
    // 注册所有工具（静态 + 动态）
    await registerAllMcpToolsForUrl(
      window.location.href,

  }
})
```

## 📊 性能考虑

### 优化措施

1. **按需加载**：只加载匹配当前域名的工具
2. **启用过滤**：自动过滤未启用的工具
3. **一次性注册**：所有工具在页面加载时一次性注册

### 待优化项

1. **缓存机制**：避免重复读取 storage
2. **延迟注册**：非关键工具延迟注册
3. **增量更新**：配置变更时只更新变化的工具

## 🛡️ 安全性

### 当前方案

- 使用 `Function` 构造函数执行用户代码
- 代码运行在页面上下文中
- 可访问页面的所有 API 和全局变量

### 风险

- 恶意代码可能窃取用户数据
- 可能影响页面正常功能
- 可能导致性能问题

### 建议改进

1. **代码审查**：添加代码静态分析
2. **沙箱隔离**：使用 Web Worker 隔离执行
3. **权限限制**：限制可访问的 API
4. **代码签名**：对官方工具进行签名验证

# Design：scroll 按百分比定位并报告当前位置

## 方案概述

`handleScroll` 在选择滚动目标后，根据是否提供 `percent` 决定滚动方式：提供时调用 `scrollTo({ top })` 直接跳转，否则沿用 `scrollBy`。结果文案按实际位移方向生成，纵向位置信息追加百分比。

## 涉及模块 / 文件

| 路径                                              | 职责                                         |
| ------------------------------------------------- | -------------------------------------------- |
| `packages/next-sdk/page-tools/schema.ts`          | 新增 `percent` 参数                          |
| `packages/next-sdk/page-tools/handlers/scroll.ts` | 按百分比跳转；位置百分比；无滚动范围时的提示 |
| `docs/webmcp-sdk/page-agent-tool.md`              | 用户文档                                     |

## 核心逻辑

- 可滚动范围：`window` 为文档高度 − 视口高度；容器为 `scrollHeight − clientHeight`。目标位置 = 范围 × `percent` / 100，`percent` 先限制在 0–100。
- 不带 `index` 时选择目标：页面本身有纵向滚动范围（不同时处于顶部和底部）就滚动页面；否则按现有规则找视口中央或可见面积最大的可滚动容器。
- 提供 `percent` 时一律按纵向处理；结果文案中的方向取实际位移的正负。
- 位置百分比 = 上方已滚过的距离 /（上方 + 下方距离），没有滚动范围时为 0。

## 依赖变更

无。

## API / 行为变更

| 符号或行为              | 变更类型 | 说明                        |
| ----------------------- | -------- | --------------------------- |
| `scroll` 参数 `percent` | 新增     | 0–100，可选                 |
| `scroll` 纵向结果       | 修改     | 位置信息末尾追加「位置 x%」 |

## 风险与兼容

- 虚拟列表的总高度可能随加载变化，同一个百分比对应的行会随之变化；结果附带的位置百分比可用于下一步微调。
- 「滚到底才加载下一页」的列表，`percent: 100` 可以触发加载，加载后位置百分比会变小。

# 快速入门

**TinyRobot AI助手** 是一个运行在 Chrome / Edge 等 Chromium 浏览器中的 AI 扩展插件。它把大模型「装进」浏览器侧边栏：你用自然语言下达任务，AI 自动打开网页、阅读页面内容、点击与填写表单，完成跨页面的连续操作；同时它还能调用网页上已注册的原生 WebMCP 工具，把业务系统的能力直接交给 AI 使用。

除对话之外，扩展还内置了一批开箱即用的插件（AI 总结、Markdown 下载、DOM 元素抓取等），并在页面上提供**悬浮球**与**右键菜单**两个快捷入口；通过 WebSocket 桥接本地 CLI 后，侧边栏还能操作你本地的工作目录，完成生成 PPT、运行本地命令等任务。

## 它能做什么

- **网页自动操作**：打开 / 切换 / 关闭标签页，读取页面内容，点击、填写、选择、滚动，完成多步骤任务。
- **页面工具调用**：自动发现并调用目标网页注册的原生 WebMCP 工具（`document.modelContext`），无需改造网站即可让 AI 使用业务能力。
- **内置插件**：右键 AI 总结、导出为 Markdown、DOM 元素选取、内容助手等，随开随用。
- **快捷入口**：任意网页上的悬浮球与右键菜单，一键唤起常用 AI 能力。
- **本地协同**：通过 WebSocket 连接本地 CLI（`@opentiny/webmcp-cli`），在侧边栏操作本地工作目录，例如生成 PPT、执行本地开发命令。
- **账号与额度**：注册登录后即可使用平台提供的免费 AI 额度，也可在「模型设置」中接入自有模型。

## 适用场景

| 场景             | 典型任务                                  | 主要依赖                            |
| ---------------- | ----------------------------------------- | ----------------------------------- |
| 操作你的业务系统 | 「打开控制台，查询昨天的告警并汇总」      | 页面 WebMCP 工具、网页自动操作      |
| 适配第三方网站   | 「在掘金搜索 WebMCP，总结前三篇文章」     | 网页自动操作（`web_page_operator`） |
| 通用网页处理     | 总结文章、导出 Markdown、抓取元素样式信息 | 内置插件、悬浮球、右键菜单          |
| 连接外部 AI 助手 | 在 Claude Desktop / Cursor 中遥控浏览器   | CLI WebSocket 桥接                  |
| 本地工作协同     | 「在当前工作目录生成一份项目汇报 PPT」    | CLI WebSocket 桥接、本地工作空间    |

## 五分钟上手

### 步骤一：安装扩展

要求 Chromium 内核版本 >= 120（Chrome、Edge 等）。

1. 下载扩展压缩包并解压到一个**固定目录**（安装后不要移动或删除该目录）。
2. 打开 `chrome://extensions/`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择刚才的解压目录。

完整步骤与截图见 [安装指南](./install.md)。

### 步骤二：打开侧边栏

点击浏览器工具栏上的 TinyRobot 图标即可展开侧边栏（建议先将图标「固定」到工具栏）。侧边栏是 AI 对话的主入口；打开任意网页后，页面右侧还会出现一个可拖动的**悬浮球**，作为页面内的快捷入口。

### 步骤三：注册登录，领取免费额度

1. 点击侧边栏的头像（个人中心），选择「登录 / 注册」。
2. 未登录时不能使用对话功能，登录后获得免费 AI 额度。
3. 在「个人中心 → 使用统计」中查看剩余额度与用量趋势；额度耗尽时会弹窗提示重置时间。

详见 [注册与登录](./usage/register-login.md)。

### 步骤四：发起第一次网页操作

在对话框输入自然语言任务即可，例如：

> 打开 https://juejin.cn，搜索「WebMCP」，告诉我第一条结果的标题和摘要。

AI 会依次调用 `browser_open_tab` 打开网页、`web_page_operator` 阅读并操作页面，执行期间目标页面会出现操作遮罩与模拟光标。输入框上方的技能按钮（网页 / 视频 / 电子表格 / 可视化 / PPT）可快速切换任务类型。

### 步骤五：用悬浮球与右键菜单快速调用

- **悬浮球**：点击展开快捷菜单（AI 对话、Markdown 下载等，已开启的插件会追加条目，如 DOM 元素选取、文章总结），按住可拖动位置，松手后自动吸附在侧边。
- **右键菜单**：选中文本或在空白处右键，选择「总结此内容」或「Markdown下载」。
- **DOM 元素选取**：按 `Alt+Shift+C`（Mac：`⌥⇧C`）进入选区模式，点选元素后结构化信息复制到剪贴板，`Esc` 退出；默认仅在 `localhost` 与 `127.0.0.1` 生效，可在插件配置中扩充白名单。

## 能力速览

### 浏览器与页面工具

| 工具                                                             | 作用                                                                                                            |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `browser_open_tab`                                               | 打开新标签页并加入工作区                                                                                        |
| `browser_list_tabs` / `browser_switch_tab` / `browser_close_tab` | 列出、切换、关闭工作区标签页                                                                                    |
| `web_page_operator`                                              | 网页子 Agent：接收自然语言指令，在目标页面自主完成多步操作                                                      |
| `page-agent-tool`（页面注入）                                    | 页面级原子操作：`browserState`、`searchTree`、`click`、`fill`、`select`、`hover`、`scroll`、`executeJavascript` |

::: tip
`web_page_operator` 只能操作 `http(s)` 网页。若当前是空白页或 `chrome://` 等浏览器内部页，AI 会先调用 `browser_open_tab` 打开网页再继续。
:::

### 页面原生 WebMCP 工具

如果目标网页已通过标准 WebMCP API（或 `@opentiny/next-sdk` 的 `document.modelContext.registerTool` / `registerPageAgentTool`）注册了工具，扩展会自动发现并代理给模型，AI 可以像调用内置工具一样调用它们。为页面接入工具的方法见 [WebMCP-SDK 快速开始](../guide/quick-start.md)。

### 自定义 WebMCP 脚本

不想改动网站源码？在「配置页 → WebMCP 管理」中编写脚本，按域名匹配规则注入目标页面并注册工具，即可为任意网站补充 AI 能力。

### 内置插件一览

| 插件                                                                         | 入口                   | 默认状态       |
| ---------------------------------------------------------------------------- | ---------------------- | -------------- |
| 悬浮助手                                                                     | 页面悬浮球             | 常驻，不可关闭 |
| 核心工作区 / 核心技能 / 网页 MCP 代理 / 网页代理 Agent / 用户自定义 MCP 脚本 | 内核能力，无独立入口   | 常驻，不可关闭 |
| 右键 AI 总结                                                                 | 右键菜单「总结此内容」 | 开启           |
| 导出为 Markdown                                                              | 右键菜单、悬浮球       | 开启           |
| DOM 元素选取                                                                 | 悬浮球、快捷键         | 关闭           |
| 内容助手（文章总结、帮写）                                                   | 悬浮球、右键菜单       | 关闭           |
| CLI WebSocket 桥接                                                           | 侧边栏桥接状态徽章     | 关闭           |

业务插件均可在「配置页 → 功能管理」中按域名开启或关闭，详见 [功能管理](./setting/plugin-config.md)。

### 连接本地 CLI（可选）

通过本地 WebSocket 桥接（`127.0.0.1:18999`），扩展可以与本地 CLI 双向协同：侧边栏让 AI 在你的本地工作目录执行命令，外部 Agent 也能遥控浏览器。

1. 准备 Node.js 环境，在终端执行 `npx @opentiny/webmcp-cli --mode wxt token`，首次执行会自动拉起本地桥接服务并输出配对 Token。
2. 在「配置页 → 功能管理」中开启「CLI WebSocket 桥接」插件。
3. 点击侧边栏输入框旁的桥接状态徽章，粘贴（或复制）Token 完成配对并开启连接。
4. 点击「本地工作空间」按钮为当前会话绑定本地文件夹；不绑定时在默认隔离目录中执行。
5. 在对话中下达本地任务，例如「在当前工作目录生成一份项目周报 PPT」或「运行 npm run dev 并把报错贴给我」。

::: warning 安全提示
CLI 桥接会在本地执行 shell 命令，请仅在受信任的开发环境开启，并妥善保管 Token。该能力当前为研发中（development）阶段插件，发布版本中可能默认不注册。
:::

反向使用：把 CLI 作为 MCP Server 接入 Claude Desktop、Cursor 等宿主，即可在这些工具中遥控你的浏览器：

```json
{
  "mcpServers": {
    "tiny-robot": {
      "command": "npx",
      "args": ["-y", "@opentiny/webmcp-cli", "--mode", "wxt", "mcp"]
    }
  }
}
```

## 常见问题

- **悬浮球或右键菜单没出现**：确认对应插件已在「功能管理」中开启；悬浮球还需检查「悬浮球设置」中的站点黑名单；配置修改后刷新页面。
- **提示「未连接到本地 CLI 桥接服务」**：先执行 `npx @opentiny/webmcp-cli --mode wxt token` 拉起服务，再在桥接徽章中核对 Token 是否一致。
- **AI 提示找不到可操作的网页**：当前标签页是空白页或浏览器内部页，先让它打开一个 `http(s)` 网页。
- **额度用完了**：在「使用统计」查看重置时间；或在「模型设置」中配置自有模型继续使用。

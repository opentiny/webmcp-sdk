# 界面说明

## 初始对话框界面说明

![初始对话框界面](../assets/images/extension/start-sidepanel-ui.png)

1. 侧边栏可以折叠与展开，它有新建任务，即创建一个新会话， Skill技能是打开当前插件拥有的技能列表，管理技能的话需要在选项设置中修改。 历史会话列表，点击可以切换到历史会话。登录按钮打开登录页，选项按钮打开插件的选项页面。
2. 顶部的图标可以切换深色主题和浅色主题。 移动端扫码是用手机扫码，它会生成一个携带当前会话信息url,在手机上预览。

3. 对话输入框，输入用户的问题。 深度思考和联网搜索和 生成式UI按钮是打开相应的模式，它们依赖模型的能力。 之后是模型选择器，用于切换不同的大模型， 扩展按钮在右侧打开抽屉弹窗，可以控制当前对话使用哪些工具函数，此处不展开讨论，详细请看 ./extension-and-mcp.md 的文档（现在还没有写好，未来会写好的）。

## 对话界面说明： `思考 `, `工具调用` `ai消息底部工具` `对话导航`

![对话界面](../assets/images/extension/chat-sidepanel-ui.png)

1. 思考链的渲染
2. 调用工具的渲染，可以展开工具的参数和返回值
3. AI消息底部工具栏可以重复对话和复制对话结果
4. 对话列表导航： 显示当前上下文的每一轮的对话，点击迅速跳转到相应的对话

## 悬浮球说明：

启用浏览器插件后，默认会在用户页面产生一个悬浮球，用于快速操作一些内置插件功能

![悬浮球界面](../assets/images/extension/float-ui.png)

1. 悬浮球可以拖动并松手时自动吸附在左右2边
2. 左键点击出现插件菜单，点击触发插件菜单功能
3. 右键点击出现了隐藏悬浮球和设置菜单。 隐藏悬浮球有3种方式： 本次隐藏，刷新后出现； 当前网站禁用，是禁用当前域名，后续打开这个域名时，都不出现悬浮球； 永久禁用是在所有网页都隐藏。 要恢复它的显示，请在设置中的`悬浮球管理`中打开， 请参考 ..\setting\floating-ui-config.md 的文档（现在还没有写好，未来会写好的）。 设置菜单直接打开插件的选项设置页面。

4. 某些插件执行任务时，悬浮球会显示任务的当前状态，点击停止可以停止当前任务。

# Bug 中文复现场景模板

用于 Issue 描述与测试用例命名。自动化测试落在 **主责包** `packages/<pkg>/test/`，不要写成 Spec。

## 字段

- 影响包 / 模块：
- 版本（`@opentiny/next-sdk` 等）：
- 环境（浏览器 / Node）：
- 前置条件：
- 复现步骤：
  1.
  2.
  3.
- 期望结果：
- 实际结果：
- 相关测试文件（修复后填写）：`packages/<pkg>/test/...`

## 测试命名约定

```ts
it('复现：<中文场景简述> —— 前置…；步骤…；期望…', () => {
  // ...
})
```

PR Gate 对 Bugfix 会检查 `Repro test` 路径及文件中含 `复现：` 关键字。
